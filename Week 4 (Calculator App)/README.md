# Week 4 (Calculator App)

**Aim:** Create a native calculator for addition, subtraction, multiplication, and division.

## Files
- `activity_main.xml` — two number fields, four operation buttons, and a result TextView.
- `MainActivity.java` — performs the selected operation and checks empty input and division by zero.
- `AndroidManifest.xml` — declares the launcher activity.
- `Output/` — initial and calculated-result screenshots from the lab manual.

**Package:** `com.example.calculatorapp`
