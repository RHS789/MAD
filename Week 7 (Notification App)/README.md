# Week 7 (Notification App)

**Aim:** Create a notification and show a Toast when it is added.

## Files
- `activity_main.xml` — one button to create a notification.
- `MainActivity.java` — creates the notification channel, displays the notification, and shows a Toast.
- `AndroidManifest.xml` — includes the Android 13+ notification permission.
- `Output/` — output screenshots from the lab manual.

## Run
Create an Android Java project, use package `com.example.notify`, copy these files into the matching Android project locations, and run on an emulator/device. Allow notification permission when prompted. On Android 8.0+, the app creates a notification channel.
