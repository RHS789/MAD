# Week 10 (Open URL App)

**Aim:** Read a URL from a text field and open it in a browser using an Intent.

## Files
- `activity_main.xml` — URL input and Open in Browser button.
- `MainActivity.java` — validates empty input, adds `https://` if missing, and opens the URL.
- `AndroidManifest.xml` — launcher activity.
- `Output/` — app input and browser screenshots from the lab manual.

Create an Android Java project with package `com.example.openurlapp` and copy the files into the matching project locations.
