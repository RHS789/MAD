# Week 3 (Candidate Details App)

**Aim:** Display candidate names in a list. Selecting a name opens a second screen with that candidate's details and a Back button.

## Files
- `activity_main.xml` — ListView for candidate names.
- `activity_detail.xml` — TextView and Back button.
- `MainActivity.java` — fills the list and sends the selected details through an Intent.
- `DetailActivity.java` — displays the selected details and closes to return.
- `AndroidManifest.xml` — registers both activities.
- `Output/` — list and details screenshots from the lab manual.

**Package:** `com.example.nameapp`
