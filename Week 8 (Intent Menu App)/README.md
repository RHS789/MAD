# Week 8 (Intent Menu App)

**Aim:** Use three buttons and Intents to open the phone dialer, a website, and the SMS app.

## Files
- `activity_main.xml` — three action buttons.
- `MainActivity.java` — uses `ACTION_DIAL` and `ACTION_VIEW` Intents.
- `AndroidManifest.xml` — launcher activity; no special permissions are needed for these actions.
- `Output/` — main screen, dialer, browser, and SMS screenshots from the lab manual.

## Sample actions
- Dialer: `1234567890`
- Website: `https://www.google.com`
- SMS: opens the SMS app with `Hello! This is a test message.` filled in.

Create an Android Java project with package `com.example.intentmenuapp` and copy the files to the matching project locations.
