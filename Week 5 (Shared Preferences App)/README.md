# Week 5 (Shared Preferences App)

**Aim:** Save a user's name, age, and gender with SharedPreferences and load the saved values when the app restarts.

## Files
- `activity_main.xml` — name, age, and gender fields, Save button, and output TextView.
- `MainActivity.java` — saves values in private SharedPreferences and loads them in `onCreate`.
- `AndroidManifest.xml` — declares the launcher activity.
- `Output/` — saved-information screenshot from the lab manual.

**Package:** `com.example.sharedprefs`
