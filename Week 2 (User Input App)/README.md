# Week 2 (User Input App)

**Aim:** Enter a user's name, contact number, and city, then display the values in a TextView.

## Files
- `activity_main.xml` — three EditTexts, a Submit button, and a TextView.
- `MainActivity.java` — reads the fields when Submit is clicked and displays them.
- `AndroidManifest.xml` — declares the launcher activity.
- `Output/` — output screenshot from the lab manual.

**Package:** `com.example.userinputapp`

Create an Android Java project with AndroidX AppCompat, then copy the files into the matching `res/layout`, `java`, and `manifests` locations.
